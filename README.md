# 🚵 Programa Funcional MTB

Programa de treinamento funcional complementar ao Mountain Bike — desenvolvido para **performance e longevidade esportiva**.

## 📋 Sobre o Programa

- **8 semanas** de progressão estruturada
- **3 treinos semanais** (Treino A, B e C)
- **40–60 minutos** por sessão
- Equipamentos: peso corporal, faixas elásticas, halteres leves, bosu (opcional)

## 🎯 Objetivos

- Mobilidade articular e flexibilidade
- Equilíbrio e propriocepção
- Fortalecimento de core profundo
- Resistência muscular localizada
- Prevenção de lesões
- Melhora da eficiência biomecânica no MTB

## 🏋️ Estrutura dos Treinos

| Treino | Foco Principal |
|--------|---------------|
| **A ⚡** | Core Profundo · Cadeia Posterior · Lombar |
| **B 🔥** | Glúteos · Quadríceps · Equilíbrio · Propriocepção |
| **C 🏔️** | Ombros · Cintura Escapular · Panturrilhas · Integração |

## 🗓️ Fases de Progressão

| Semanas | Fase | Foco |
|---------|------|------|
| 1–2 | Adaptação | Técnica e mobilidade base |
| 3–4 | Desenvolvimento | Volume + instabilidade |
| 5–6 | Intensificação | Resistência + fadiga controlada |
| 7–8 | Consolidação | Integração neuromuscular |
